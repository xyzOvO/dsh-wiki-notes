# 微调与检索增强

> 定义：两条让模型「知道更多」的路线——改权重，还是改上下文。

## 一句话区分

- **微调**把知识写进参数：改的是「模型会什么」。
- **检索增强**把知识放进上下文：改的是「模型此刻看到什么」。

## 该选哪个

| 你的问题 | 选 |
| --- | --- |
| 知识天天变，改一次就要重训 | 检索增强 |
| 要改的是说话风格、输出格式 | 微调 |
| 需要引用原文、能追溯到出处 | 检索增强 |
| 要在小模型上压成本、提速度 | 微调（蒸馏） |

两者不冲突：先用检索解决「不知道」，再用微调解决「不会按要求说」。

## 常见误判

把「模型答错了」直接归因于「知识不够」，然后去微调——很多时候真正的原因是
**上下文里根本没有那段资料**。先查检索，再谈训练。
