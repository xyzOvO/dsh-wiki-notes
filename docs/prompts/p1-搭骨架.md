# P1 · 让 agent 给你搭一个库的骨架

**什么时候用**：第 0 分钟，还没有库。
**贴给谁**：随便哪个能读写文件的 AI（Claude / GPT / DeepSeek / 本地模型都行），在**你准备放库的那个空目录**里。

---

## 提示词

```
我要在这个目录建一个个人知识库。请按下面的规矩做，做完把目录树打给我。

结构：
1. 原始资料-raw/          只读，我往里丢东西，你永远不改
2. 知识层-wiki/           你来写
   - index.md            内容索引
   - log.md              只追加的时间线
   - 总览-overview.md     全库当前认知状态
   - 资料-sources/       一份资料一页摘要
   - 概念-concepts/      定义、机制、术语
   - 实体-entities/      人、组织、产品、作品、事件
   - 对比-comparisons/   A vs B
   - 综合-syntheses/     跨页判断
   - _模板-templates/    页面骨架
3. AGENTS.md              规则，你每次开工先读它

先只做骨架，不要创作内容。具体：
- 建目录（空目录也建，Obsidian 才显示得出来）
- 每个类型各写一个模板，放进 _模板-templates/
- index.md 写清格式：`- [[页名]] — 一句话摘要（N 份资料，更新于 YYYY-MM-DD）`，先留空
- log.md 写一条：`## [今天] init | 初始化知识库`
- 总览-overview.md 写四块占位：这个库在讲什么 / 各页成熟度 / 未裁决的分歧 / 待补缺口

做完告诉我：目录树 + 下一步该做什么。
```

---

## 验收标准（逐条打勾，缺一条就让它补）

- [ ] `原始资料-raw/`、`知识层-wiki/` 两层都在，且 agent 明确说出「raw 只读」
- [ ] `知识层-wiki/` 下六个类型目录 + `_模板-templates/` 都在
- [ ] `index.md`、`log.md`、`总览-overview.md` 三个文件都在
- [ ] `log.md` 有一条 init 记录
- [ ] 模板文件里有 frontmatter（七字段），不是空白页
- [ ] 你没让 agent 编任何内容——此刻库里应该一页真东西都没有

## 失败怎么办

- **目录建了但 Obsidian 里看不见**：空目录 Obsidian 不显示，让 agent 每个目录放一个 `.gitkeep` 或先写一页占位。
- **agent 顺手给你写了十页"示例内容"**：删掉。库的第一批内容必须是你自己的资料，示例内容会污染检索和你的判断。
- **它把规则写进了 `README.md` 而不是 `AGENTS.md`**：改名。`AGENTS.md` 是 agent 工具的约定文件名，放在根目录才会被自动读到。
