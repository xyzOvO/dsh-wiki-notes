# P3 · 摄入一份资料

**什么时候用**：每次往 `原始资料-raw/` 里丢了一篇文章 / 一份 PDF / 一段字幕之后。
**贴给谁**：同一个 agent。**一次一两篇**，别一次丢二十篇。

---

## 提示词

```
摄入 原始资料-raw/<具体文件名>。按 AGENTS.md §6.1 走，重点做第 4 步「整合」。

具体要求：
1. 读全文再动手。读不了（扫描件、图片多的 PDF）就直说，别猜内容。
2. 先给我 3–5 条要点，等我确认重点，再写。
3. 写资料页：一句话总结 / 核心要点 / 关键引文（每条必须带 raw 文件的行号）/ 可信度评估。
   引文找不到位置就不要写引文，宁可写成「转述（非逐字）」。
4. 整合：逐个检查已有页面，告诉我「这份资料改变了哪几页、怎么改的」，以及哪些页你判断不受影响。
5. 有新旧冲突：保留旧内容，就地标 ⚠️，别直接覆盖。
6. 改完更新 index.md 与总览，log.md 记一条 ingest。
7. 最后给我一份清单：新建 N 页 / 修改 M 页 / 新增红链 K 个。
```

---

## 验收标准

- [ ] 资料页里每条引文都有 `文件.md:行号`，没有"见某文件"
- [ ] 有「整合」步骤的明确交代（哪些页被改了、为什么）
- [ ] 冲突用 `> ⚠️ 已被更新` 就地标注，旧内容还在
- [ ] `index.md` 有这一行，`总览` 有变化，`log.md` 有一条
- [ ] 红链被如实报出来（没建页的概念先链出去，不硬造页）
- [ ] 你抽查一条引文，能对上原文

## 失败怎么办

- **它只写摘要、不碰已有页**：这是最常见的偷懒。直接问「这份资料有没有改变《X》《Y》？逐页说」。
- **它把原文大段复制进 wiki**：删回去，只留摘要 + 引文。原文留在 raw。
- **引文对不上原文**：这是红线。让它在原文里定位到具体行，定位不到就把那条从「关键引文」挪进「转述」。
- **一口气生成了十几页三行小页**：停。这会长出一堆平行摘要，不是网。宁可少建页、把已有页写厚。
